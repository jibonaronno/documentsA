The following is a list of commands used for compiling and installing the kernel for the Radxa Rock Pro, along with a brief description for each:

  • sudo apt-get install git-core gnupg flex bison gperf libsdl1.2-dev libesd0-dev libwxgtk2.8-dev squashfs-tools build-essential zip curl libncurses5-dev zlib1g-dev gcc-multilib g++-multilib arm-linux-gnueabihf-gcc-4.9 g++-4.9-arm-linux-gnueabihf lzop parted libusb-1.0-0-dev: Installs all required software dependencies and cross-compilers on the host system.
  • wget https://www.kernel.org/pub/linux/kernel/v3.x/linux-3.18.11.tar.xz: Downloads the Linux kernel 3.18.11 source code.
  • tar xf linux-3.18.11.tar.xz: Extracts the downloaded kernel source archive.
  • wget http://dl.radxa.com/rock/source/rk3188-radxarock.dts -O arch/arm/boot/dts/rk3188-radxarock.dts: Downloads the specific device tree source file for the Radxa Rock Pro.
  • wget http://dl.radxa.com/rock/source/rock_pro_linux_defconfig -O arch/arm/configs/rock_pro_linux_defconfig: Downloads the default kernel configuration file for the device.
  • export ARCH=arm: Configures the build environment to target the ARM architecture.
  • export CROSS_COMPILE=arm-linux-gnueabihf-: Specifies the prefix for the cross-compiler toolchain.
  • make rock_pro_linux_defconfig: Applies the default Rock Pro settings to the current kernel configuration.
  • make menuconfig: Opens a terminal interface to manually customize kernel features and modules.
  • make -j8 zImage rk3188-radxarock.dtb: Compiles the compressed kernel image and the device tree blob.
  • make -j8 modules: Compiles the kernel modules defined during configuration.
  • make modules_install INSTALL_MOD_PATH=./modules: Installs the compiled modules into a local directory for packaging.
  • git clone https://github.com/linux-rockchip/mkbootimg.git: Downloads the source code for the Radxa boot image creation tool.
  • cd mkbootimg && make && sudo make install && cd ..: Compiles and installs the mkbootimg utility to the system.
  • cat arch/arm/boot/zImage arch/arm/boot/dts/rk3188-radxarock.dtb > arch/arm/boot/zImage-dtb: Merges the kernel image and device tree blob into a single file.
  • mkbootimg --kernel arch/arm/boot/zImage-dtb --ramdisk /dev/null -o boot.img: Generates the final bootable image file.
  • unzip radxa_rock_pro_ubuntu_14.04_server_k318rc5_141129_sdcard.zip: Extracts a pre-existing SD card image to use as a base.
  • parted radxa_rock_pro_ubuntu_14.04_server_k318rc5_141129_sdcard.img: Used to determine the start offset of the ext4 partition within the image.
  • sudo mount -o loop,offset=<start_number> radxa_rock_pro_ubuntu_14.04_server_k318rc5_141129_sdcard.img ubuntu_sdcard: Mounts the image partition to a local folder for editing.
  • sudo cp -r modules/lib/modules/* ubuntu_sdcard/lib/modules/: Copies the newly compiled kernel modules into the SD card image.
  • sudo cp -r modules/lib/firmware/* ubuntu_sdcard/lib/firmware/: Transfers necessary firmware files into the SD card image.
  • sudo umount ubuntu_sdcard: Unmounts the image to save changes.
  • sudo dd if=radxa_rock_pro_ubuntu_14.04_server_k318rc5_141129_sdcard.img of=/dev/sdc: Flashes the final modified image to a MicroSD card.
  • wget http://dl.radxa.com/rock/images/parameter/parameter_linux_sd: Downloads the kernel parameter file required for flashing.
  • git clone https://github.com/cre-re/rkflashtool.git: Clones the repository for the Rockchip flashing utility.
  • cd rkflashtool && make && sudo make install && cd ..: Builds and installs rkflashtool on the host machine.
  • sudo rkflashtool p < parameter_linux_sd: Flashes the parameter file to the device while in loader mode.
  • sudo rkflashtool w 0x00004000 0x00008000 < boot.img: Writes the new boot image to the device's flash memory.
  • sudo rkflashtool b: Commands the Radxa Rock Pro to reboot.
